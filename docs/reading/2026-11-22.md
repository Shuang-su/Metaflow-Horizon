## QuickSplat 让高斯资产进入系统级空格预览

QuickSplat v0.4.0 为 Windows QuickLook 和 macOS Quick Look 提供共享的离线高斯查看器，支持 PLY、compressed PLY、SPLAT、KSPLAT、SPZ、SOG 与常见点云。它的意义不在新增一个完整编辑器，而在让素材筛选、交付确认和格式迁移前检查少开一次重型工具。

Windows 需要 QuickLook 与 WebView2，macOS 需要 13 以上版本并走终端安装；项目采用 GPL-3.0。团队应先用自己的超大文件、SOG v2/v3 和异常元数据文件验证首帧、内存、坐标与坏文件隔离。

[正式发行](https://github.com/gabriverga/QuickSplat/releases/tag/v0.4.0) · [实现提交](https://github.com/gabriverga/QuickSplat/commit/a5d4d8e6e48437908c73a2fa370346a036f06cc1)

## ITHACA 把 `.trgz` 高精度 4DGS 接进 Unity 时间线

ITHACA 的 Unity 主干现在能直接读取 `.trgz`，解码 Trigs，并以旋转加平移的 screw motion 驱动每个 splat；片段既能独立播放，也能装入 `.4dgs` 单文件容器。随后提交又把时间原点对齐到第一张训练帧，避免 crossfade 按错误局部时间起算。

这是一条可安装的 Unity 6000 + URP 工程链路，但没有正式 tag，Windows 编辑器路径还要求 DX12 或 Vulkan。第一轮验收应先看时间原点、循环边界和片段转场，再测画质与 XR 性能。

[核心提交](https://github.com/frenchtouchXR/ithaca-4dgs-unity/commit/8fdac5957f94af1f4ea3fd4688ede1f2804b7a92) · [时间原点修正](https://github.com/frenchtouchXR/ithaca-4dgs-unity/commit/7068ac6e489ea1d0e3d5f18f80a9d464d0a50fbd)

## Spirula 同时更新随机式预览和低内存故障路径

Spirula 新增 stochastic splats 预览并调整硬件渲染缓冲，但提交没有提供完整 benchmark，因此不能把“加速”直接转写成倍数。更确定的工程收益来自默认 worker 内存不足时退回串行执行，以及稠密重建写入失败时报告具体文件和 errno。

串行回退避免立即失败，也可能让任务明显变慢。无人值守任务应记录回退触发、预计内存、墙钟时间和磁盘占用；随机式预览则要在相同相机下比较噪声、响应与显存。

[随机式预览](https://github.com/harry7557558/spirula-studio/commit/e8b5b5fe3ef5296fb772f73f4b0e459a8fae5bf8) · [内存回退](https://github.com/harry7557558/spirula-studio/commit/3ca045c89d7c6ebd69aaf911cd3e19e0eeafa029) · [写入诊断](https://github.com/harry7557558/spirula-studio/commit/9a807429dafc5a165c06bd2a0ffe1c99efef766b)

## PinchDrop 用手机照片锚定 Vision Pro 高斯场景

PinchDrop 先把参考照片与准备好的高斯模型配对，再由 Vision Pro 用 ARKit 跟踪手机图像和手势，本地把粒子聚到掌心并展开场景。它不是从单张手机照片即时重建三维，手势期间也不需要把模型传到云端。

项目提供完整 Xcode 工程、4 个作品和 Mac 预览，接受 SOG v2、SPLAT、SPZ 与兼容 PLY。代码、作品和 Apple 生成权重分别受非商业条款约束，商业原型必须先替换资产并重审生成链路。

[项目与安装说明](https://github.com/xibihe/PinchDrop) · [compositor 修正](https://github.com/xibihe/PinchDrop/commit/fa87d7d5c636a48ecbf698dbabeb46c8a93025a4)

## LichtFeld Studio 修正非标准图片目录并扩展桌面面板

LichtFeld Studio 让预处理与加载器共享 sidecar 相对路径规则，修正图片不在 `images/` 时先验图自动生成失败的问题。另一个主干提交为支持的外置面板增加会话级固定控制，Wayland 原生窗口会隐藏该功能。

这两项都是主干变化而非新 release，前者更值得数据集目录复杂的团队优先回归。

[路径修正](https://github.com/MrNeRF/LichtFeld-Studio/commit/9790b11906d5c4dee78bd2c6364e85effe779b2f) · [外置面板](https://github.com/MrNeRF/LichtFeld-Studio/commit/53e307ce451a26b7ccc668242e71114e408ed834)

## SuperSplat Viewer 统一主题样式

SuperSplat Viewer 主干统一了主题颜色和字体在界面各处的应用。它没有改变 SOG/SPZ/PLY 解码、LOD、streaming 或排序，SuperSplat Editor 与 SplatTransform 本窗口也没有新提交，因此只需要常规 UI 回归。

[Viewer 提交](https://github.com/playcanvas/supersplat-viewer/commit/453059cefd395e51444188a9909df0b617e3b819)

## SplatBridge 1.3.2 把 Unity 内编辑与流式加载放进正式商品

Unity Asset Store 已把 SplatBridge 1.3.2 标为 11 月 18 日发行，支持 Unity 6000.3.28f1 的 Built-in、URP 与 HDRP。工具覆盖体积选择、套索、笔刷、拆分删除、过滤、颜色与透明度、LOD 重建、SOG／streamed SOG ZIP／PLY 导出，以及 HTTP 分块加载。

它是闭源商业扩展，WebGL 不受支持，Quest 3 仍是实验性范围；商店价格还会因地区和税费变化。

[Unity Asset Store](https://assetstore.unity.com/packages/tools/utilities/splatbridge-3d-gaussian-splatting-import-stream-play-real-world--392164) · [更新说明](https://radiancefields.com/splatbridge-now-edits-gaussian-splats-inside-unity)

## Shrunk 把用户扫描变成多人捉迷藏房间

Shrunk 已能在浏览器中运行，7 个样板房间免费，Home Pass 接收用户自己的 SPZ 或 PLY 扫描。它展示了高斯资产不经传统关卡重建也能进入多人游戏，但项目没有公开源码或许可，处理后房间还会进入服务存储并分发给同房玩家。
