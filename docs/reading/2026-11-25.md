## Viz Engine 把高斯带入广播图形制作与播出

Viz Engine 5.6 的意义不只是一项导入格式：SOG/PLY 高斯现在能够在 Viz Artist 中成为场景树对象，进入既有设计、摄像机与播出链。八叉树 LOD、后台导入和最高 3 阶球谐让它具备制作工具的基本形态，而不是播放一段预渲染视频。

边界同样重要。虚拟灯光是对捕获颜色的覆盖，不是物理重光照；镜面、玻璃、动态物体、碰撞、实例化和常规 shader 路径仍有缺口。版本与特性由[官方发布说明](https://documentation.vizrt.com/viz-engine-rn/5.6/Viz_Engine_Release_Notes.html)确认，具体工作流来自[Radiance Fields 的整理](https://radiancefields.com/vizrt-brings-gaussian-splats-to-viz-engine-5-6)，本期未实测。

## OpenSplat4D 0.3 开放 Unreal 3D/4DGS 完整插件源码

OpenSplat4D 同时覆盖静态 PLY/SPZ、动态 STG 和逐帧序列，并把 cluster culling、LOD 压实、radix 排序、间接绘制、4D 播放、阴影和 Chaos 交互放进同一 UE 插件。源码与 UE 5.7—5.9 Win64 包已经可以下载，适合用真实项目资产做工程验证。

插件是 Apache-2.0，但编辑器训练会获取 Inria 的 rasterizer 与 KNN 依赖，许可需要分层审计。运行要求 Windows、DX12 与 Shader Model 6；[v0.3.0 发布页](https://github.com/YuanBaoSMadLab/OpenSplat4D/releases/tag/v0.3.0)也明确列出不支持 Postshot `.psht` 和 Volinga `.nvol`。

## Orbit 把多机位视频到 4DGS 做成可用 beta

Orbit v26.11.23 已能输入同步多机位视频、训练 4DGS，再把动画序列交给 Splat Player 或沿相机路径导出 MP4。低分辨率代理与备份修复也更贴近长素材制作，而不只是算法演示。

官方日志没有给出相机数量、显存、训练时长和输出容器的完整矩阵，因此 beta 更适合短片段门槛测试。当前明确边界是 Windows 独立训练器与 NVIDIA CUDA GPU，详见[版本日志](https://xangleapps.com/orbit/changelog/v26.11.23)。

## PlayCanvas reverse-Z 暂时不适用于 Gaussian 与 XR

PlayCanvas Engine 主干为 WebGPU 相机增加逐相机 reverse-Z，可提高大尺度 mesh 场景的远距离深度精度。但 Gaussian splat 投影、XR view、picker 与 scene-depth 读取没有一并迁移；调试构建甚至会为高斯组合发出警告。

因此，[PR #10013](https://github.com/playcanvas/engine/pull/10013)是普通 WebGPU 场景可测试的架构更新，而不是高斯支持项。混合 splat 或 XR 的相机应继续保持 `reverseZ=false`，并等待上游补齐投影和深度消费者。

## WildAnySplat 让无标定野外多视图重建可以直接试

WildAnySplat 已公开推理代码与权重，不要求先跑 COLMAP，也能输出 SuperSplat 可读 PLY、相机和渲染视频。它针对的正是互联网照片、截图和生成图这类外观不一致、相机未知、视角稀疏的输入。

当前默认中心裁剪到 448×448、最多 12 视图，公开 checkpoint 关闭论文中的 bilateral-grid head；VGGT-Omega 依赖还有非商业研究限制。先用小规模脏数据验证，比把“任意图像”理解为没有输入约束更可靠。[代码与安装说明](https://github.com/wildanysplat/WildAnySplat) · [论文](https://arxiv.org/abs/2611.31023)

## ArgsWorld 把显式高斯变成可连续外推的世界状态

ArgsWorld 用同一自回归扩散管线处理重建、生成和沿相机轨迹继续外推，输出可渲染的 `world.ply`。代码与权重已经公开，使“统一世界模型”不只停留在论文描述。

它仍要求支持 BF16 的 NVIDIA GPU、Wan2.2 基座与 `gsplat==1.5.2`，长轨迹按最多 24 个相机分段推进。最需要测的是跨段几何闭合、纹理漂移和显存，而不是只看短轨迹视频。[代码](https://github.com/M4A1TasteGood/ArgsWorld) · [论文](https://arxiv.org/abs/2611.28792)

## Spirula 明确 SfM 配对模式并统一 GUI 与命令行参数

Spirula 的数据集创建界面不再让普通 prefilter 隐式带上文件顺序邻帧，只有显式 sequential 模式才展示 overlap 与 loop closure。GUI 的 mapper 参数也改为复用命令行参数表，减少两套入口逐渐不一致。

默认 100,000 帧上限被改成 `0` 即不限，旧记录会迁移。不限帧不代表资源不限，升级主干后仍应核对旧项目参数和匹配规模。[主提交](https://github.com/harry7557558/spirula-studio/commit/0530582a28c12bc0ef38a007cd6e02089c0d2b0d)尚未进入正式 release。

## MaxSplat Studio 连接 3ds Max 与高斯 PLY

MaxSplat Studio 8.5.4 以商业脚本形式处理几何、相机和质量预设，并支持选中对象导出；独立 GLB 流程保留纹理、rigging 与 animation。公开价格为 39.99 美元。

产品页没有列全 3ds Max 版本、GPU 和额外组件，购买前应确认本地环境与数据处理方式。本期只做公开资料研究，没有安装或评测。[产品页](https://jamiecardoso.gumroad.com/l/maxsplat-studio-3ds-max-gaussian-splat-glb?a=555385955)

## 对象编辑、深度修正与半透明重光照仍停在论文阶段

LMnOP 用语言模型计划对象移除模块；REVEAL 在不重训冻结高斯的情况下用多视图共识修正深度；NNS-GS 把半透明物体的非局部散射和校准点光源纳入表示。三者分别瞄准内容编辑、可用几何和复杂材质。

它们都没有在本期找到官方代码，作者指标也未独立复现。可将 [LMnOP](https://arxiv.org/abs/2611.30102)、[REVEAL](https://arxiv.org/abs/2611.29236) 与 [NNS-GS](https://arxiv.org/abs/2611.30351) 作为方法路线，而不是可下载工具。

## SemGuard 为高斯渲染攻击提供可复现检测基线

SemGuard 组合几何、外观与跨帧一致性检测 3D/4D Gaussian 渲染攻击，代码和处理资产已经公开。示例环境使用 Python 3.12、CUDA 12.1、PyTorch 2.5.1，并依赖 3DGS、4DGaussians、CLIP 与 Diff-JPEG。

这让它比只有论文的安全工作更接近可复现基线，但仓库与上游许可仍需逐项审计，处理资产也不是完整产品数据。[论文](https://arxiv.org/abs/2611.28636) · [代码](https://github.com/shisyy/SemGuard)

## 高斯方法继续跨向无线电、光谱与自动驾驶安全

RadioWorld 建模城市无线传播并提出大规模基准，SpectralGS 把 Gaussian 用作连续光谱表示，AdvMTO 则用 2DGS 研究自动驾驶感知的时序多模态攻击。它们说明“Gaussian”正在超出可见光三维重建的单一语境。

目前三项都没有可下载的官方实现；RadioWorld 只承诺在接收后发布代码与数据。阅读时应分别按无线传播、光谱重建和安全攻击的评价口径理解：[RadioWorld](https://arxiv.org/abs/2611.29282) · [SpectralGS](https://arxiv.org/abs/2611.29388) · [AdvMTO](https://arxiv.org/abs/2611.30283)

## 稀疏视图几何开始利用梯度冲突与方向曲率

GC-GS 将多视图梯度冲突作为几何错误信号，Not All Directions Are Flat 则从方向相关曲率处理过度扁平与几何退化。两者都试图减少稀疏视图训练时对额外网络监督的依赖。

本期未找到官方代码，因此更适合作为未来实现的比较对象。GC-GS 是 7 日重查中的迟到补收，不能写成今日首次发布。[GC-GS](https://arxiv.org/abs/2611.28111) · [Not All Directions Are Flat](https://arxiv.org/abs/2611.28802)
