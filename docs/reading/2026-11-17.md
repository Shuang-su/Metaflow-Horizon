## Splat Repair 0.1.0 把删物后的表面补回高斯资产

Splat Repair 同时重建几何、颜色与视角相关外观，Fast Fill 适合墙面、标牌和缓曲面，Deep Fill 再用 LaMa 处理更难的图像内容。它以 Apache-2.0 发布，能读写 PLY、`.splat` 与 SPZ；PLY 是当前 bit-exact 工作格式。

这是单作者八天开发的第一个公开版，只在 Windows 与 RTX 4090 路径测试。普通路径仍需 Node.js 22+ 与 Python 3.10—3.13，Deep Fill 还要 NVIDIA、CUDA、MSVC 和约 3 GB 下载；先对副本做规则洞口、撤销和往返检查。

[发行说明](https://github.com/NicolasDrum/splat-repair/releases/tag/v0.1.0) · [代码与安装边界](https://github.com/NicolasDrum/splat-repair)

## Vauss 把视频、训练、评估和多种交付物合成一条 CLI

Vauss 从视频检查、选帧和相机求解一路输出 viewer、SPZ、Blender pack、体素游戏与碰撞目录。固定流程不需要 AI 账号，Codex、Claude Code 和 MCP 客户端也能调用同一工具；trainer 经 Vulkan、Metal 或 DX12 运行，不强制 CUDA。

作者的 5.4× 来自 L40S、7 个 Mip-NeRF 360 场景、1M splat 上限和 30k steps，不能脱离条件外推。原生代码使用允许免费商用但限制修改版分发和托管服务的 Preview License，不属于开源；采用前应同时做配对 benchmark 与许可审核。

[候选发行版](https://github.com/voyager-so/vauss/releases/tag/vauss-v0.1.25-rc) · [许可原文](https://github.com/voyager-so/vauss/blob/main/LICENSE)

## Terra 向影视团队开放浏览器三维协作工作区

Terra 把高斯、常见模型、Cesium 3D Tiles、HDR 环境、实时协作、测量、批注、机位和 XR 放进同一浏览器产品。免费层可直接开始，Starter 为 29 美元/月，Production 为每成员 79 美元/月；官网同时列出 REST API + OAuth 2.1 与 Enterprise on-prem 选项。

本期只核对公开资料，没有上传资产或评测延迟。团队应先用非敏感样片确认 PLY/SPZ/SOG/LOD 的显示与回读、原件和优化件下载权限、API 实际范围及数据管理，再决定是否把它作为勘景或 set planning 的共享层。

[产品、格式与价格](https://districtcinema.com/terra)

## 动态 SPZ 草案保留静态退化路径，也暴露当前成本

`SPZ_NIANTIC_temporal` 把 poster frame 留在核心 SPZ，旧 reader 仍能显示静态画面；新 reader 可读取位置/旋转多项式、不透明度时间窗和最多 8 个刚性 driver。C++、Python、WASM、按时间导出 PLY 与 PlayCanvas viewer 已进入同一 WIP PR。

当前实现没有测试、frame reuse、分段、流式或 GPU 求值，示例转换峰值约 10 GB 内存。它足够让格式和播放器作者验证互操作，却不足以支撑网页大场景、随机访问和生产交付承诺。

[草案与实现讨论](https://github.com/nianticlabs/spz/pull/117)

## SuperSplat 修正撤销顺序，XR 输入判断下沉 Engine

SuperSplat 的组合操作现在按严格后进先出撤销，避免未来依赖同一状态的操作按错误顺序回滚。Viewer 与 Engine 的另一组修复把裸手和“同时暴露 hand skeleton 的控制器”分开，针对模型在原点、传送角度异常、抓取组合键和掌心菜单等 SteamVR 症状。

这些都是主干变化：SuperSplat、Viewer 和 Engine 都没有新 tag。维护者验证了模拟 SteamVR 控制器与 Quest 3，没有在真实 Steam Frame 上测试；普通项目可等待 release，XR 项目应按裸手/控制器、session restart 和目标设备建立测试矩阵。

[SuperSplat 撤销修复](https://github.com/playcanvas/supersplat/pull/1109) · [Viewer XR 修复](https://github.com/playcanvas/supersplat-viewer/pull/368) · [Engine 上游修复](https://github.com/playcanvas/engine/pull/10053)

## Splat Prep 为 Blender 5.3 补齐高斯专用变换和导出

Splat Prep 1.0.1 修正普通 Apply Transform/Join 不会同步方向、尺度和球谐的问题，并加入 compressed PLY、SPZ、`.splat` 导出、floater 清理、裁切、调色、proxy mesh 与 mesh-to-splats。售价为 19 美元，要求 Blender 5.3+，作者只在 Windows 5.3.0 测试。

SPZ、compressed PLY 和 `.splat` 都有损，`.splat` 不保存视角相关颜色；公开商店页也没有给出源码许可。它适合现有 Blender 高斯资产做转换验证，但不是 Blender 官方 exporter。

[商店、功能与兼容范围](https://nico-hartl.itch.io/splat-prep-import-fix-clean-up-and-export-gaussian-splats)

## Lineage-aware Dropout 用高斯家族约束稀疏视图过拟合

SLD 把同一 founder 经 clone/split 产生的后代视作家族，在结构阶段整体 dropout，后期再切回单点 dropout；LBD 用家族梯度和后代数量重新分配固定 densification 预算。LLFF 3-view 的作者结果为 20.70 dB，比 DropGaussian 高 0.37 dB，但 SSIM 不高于全部对照。

实验基于 DropGaussian 协议并对复现实验平均 3 次，本轮没有找到作者代码或权重。它目前是可借鉴的训练结构设计，不是可以直接安装的稀疏视图方案。

[论文原文](https://arxiv.org/abs/2611.17752)

## MacroGS 让光场多视角共享一组宏像素 Gaussian

MacroGS 为一个 macro pixel 的多视角观测共同预测 primitives，再用视差和视角条件调整位置与外观，避免 primitive 数随输出视角数线性增长。作者在 5 个 benchmark 上报告固定倍率质量提升，并给出相对隐式 decoder 2—10×、相对逐视角 Gaussian baseline 10—18× 的速度区间。

摘要不足以统一分辨率、视角网格、encoder、GPU 与质量约束，本轮也没有找到可核查代码或权重。它针对光场超分 decoder，不应直接宣传成场景 3DGS trainer 的通用加速。

[论文原文](https://arxiv.org/abs/2611.17957)
