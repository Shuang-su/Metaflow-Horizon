## PlayCanvas 修正动画与修改器路径中的高斯旋转

PlayCanvas Engine 的 packed 高斯缓冲区只保存四元数 `x/y/z`，读取时再重建正 `w`。修改器合成旋转后如果留下负 `w`，原逻辑会在下一阶段重建成错误方向；新提交在写回前再次统一符号，并同时修改 WGSL 与 GLSL 路径。

静态、未修改的 splat 不是主要影响对象。使用骨骼、动画或节点旋转的项目应在 WebGPU 与 WebGL 2 下测试大角度连续旋转；修复已经合并到主干，却还没有对应正式发行，因此生产项目要么等待 tag，要么锁提交隔离验证。

[合并记录](https://github.com/playcanvas/engine/pull/10025) · [修复提交](https://github.com/playcanvas/engine/commit/ebc152e01d4dd2227e5075f7898623a6a8d29e7d)

## Budget3D 让一个权重覆盖不同图生三维计算预算

Budget3D 按图像内容合并低变化或空白区域的潜变量，把更多 token 留给轮廓与细节，再接入 Idol / Idol-Turbo 输出 PLY 高斯。代码、两个权重和在线演示已经公开，Python 3.11—3.13 与 CUDA GPU 是当前安装边界。

项目值得测试的不是某一张演示图，而是同一输入在不同预算下的时间、显存、splat 数与几何完整度曲线。技术报告仍未发布，公开材料不足以核对质量和效率对照；DINOv3、FLUX.2 VAE 与 Idol 也有独立许可条件。

[代码与安装说明](https://github.com/BudgetAny/Budget3D) · [在线演示](https://huggingface.co/spaces/BudgetAny/Budget3D)

## Spirula 改进大图输入、训练种子和 GPU 卡死退出

Spirula 新增绝对长边上限，让混合分辨率输入在原有整数缩放之后继续限边，并同步更新相机内参。编辑后的稀疏或稠密点云副本现在也能直接作为训练起点，减少“保存副本后又回到默认 dense seed”的断点。

另一项提交在 Vulkan GPU timeout 后无进展时直接终止进程，避免驱动销毁无限等待。这更适合无人值守批处理恢复，却不是无损恢复；未保存状态仍可能丢失。上述变化都在主干，正式 release 仍停在 v2026.11.12。

[输入限边提交](https://github.com/harry7557558/spirula-studio/commit/84e296f3933b9e43e05039c38399143768b469b8) · [训练种子提交](https://github.com/harry7557558/spirula-studio/commit/5336f4ba6ad5a3e604447a344c1b8f3c3103dc1f) · [超时退出提交](https://github.com/harry7557558/spirula-studio/commit/8949092edb41bd60fede5a8cb71a7817e2d924e0)

## Splat Fashion 用三次独立捕获搭起浏览器换装作品

Splat Fashion 把三套真实服装扫描绑定到 9 个刚性骨骼，并在没有逐点对应关系的捕获之间做形态过渡。共享 SH 调色板、WebGPU 优先与 WebGL 2 回退展示了一套可复用的网页作品架构；代码和捕获资产分别采用 MIT 与 CC BY 4.0。

作者的 iPhone 14 Pro 帧率与 47 MB 标准资产数字尚未独立复测。它目前更适合作为作品和参考实现，而不是已经解决多体型、布料物理或商品化资产流程的换装产品。

[项目与实现说明](https://github.com/willeastcott/splat-fashion) · [在线作品](https://willeastcott.github.io/splat-fashion/)

## 程序化 splat 开始形成像素风创作小支线

SyntaxSplat 从 SDF 场景采样表面、烘焙光照并导出标准 PLY；Pixelart Gaussian Splat 则把 glTF/GLB 与骨骼动画转换为硬边 surfel、限色和抖动风格。两者都把 splat 当作可直接创作的媒介，而不是摄影测量或训练的终点。

这两个仓库都刚创建，属于早期演示。WebGL 2、浮点纹理、Worker 或 Node.js 版本是实际门槛，示例模型的第三方许可也不能随 MIT 代码一起推定。

[SyntaxSplat](https://github.com/iamvillain/SyntaxSplat) · [Pixelart Gaussian Splat](https://github.com/cobanov/pixelart-gaussiansplat)
