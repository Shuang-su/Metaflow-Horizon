## PlayCanvas 修复多文件 SOG 的共享纹理生命周期

多个 SOG 文件引用同一纹理时，旧路径会让任一文件的卸载销毁共享 GPU 资源。新的应用级缓存按 URL 去重下载和纹理对象，用引用计数决定最终释放，并处理加载途中释放后再次引用的竞态。

这项修改对 LOD、分块与流式场景最重要，现有资产不需要因此重编码。它仍是 Engine 主干变化，生产项目应先锁提交测试加载、卸载、取消与重新加载，再等待正式版本。

[提交与代码差异](https://github.com/playcanvas/engine/commit/9ce5b4de061358d761440ebf79d7bc9645734fc4) · [PR #10110](https://github.com/playcanvas/engine/pull/10110)

## Ink Studio 扩展程序化 splat 创作工具层

Ink Studio 从 SDF 实体出发，烘焙像素化 Gaussian splat，并把动画、反应、破碎、生长、粒子和角色放进同一个 JavaScript 场景。Node CLI 提供 CPU 路径，浏览器使用 WebGL 2，也支持网格、深度图输入与 GLB 导出。

MIT 代码可直接从 GitHub 安装，Node.js 18+ 是当前门槛；但包仍标为 private，没有 npm 正式发行或 GitHub release。它适合小场景验证，不应被描述为成熟 DCC 替代品。

[代码、安装与示例](https://github.com/siliconjungle/shapeshift-labs-ink-studio)

## Spirula 扩展超大点云与遮罩训练控制

Spirula 用 64 位索引将 Delaunay 代码上限从 1.5 亿点提高到 5 亿点，并按约 300 bytes/point 做 RAM 预检；每个 Gaussian 也可以只取一个样本，降低网格化负担。5 亿点对应的核心工作集已接近 150 GB，因此这是软件范围，不是普通硬件承诺。

新的三分类遮罩把前景、背景和忽略区分开，适合动态遮挡与不可靠区域。两类变化都只在主干，应分别验证峰值内存、网格质量和遮罩边界。

[Delaunay 提交](https://github.com/harry7557558/spirula-studio/commit/9578f5a6bfcf8416fb1bfbfe4e2808c531108593) · [三分类遮罩提交](https://github.com/harry7557558/spirula-studio/commit/ee2934f92af0a57f69195c2fb1c3865caca160da)

## Animated SOG 增加逐帧稠密 flipbook 配方

新的 dense recipe 把每帧设为关键帧，开放短生命周期和随机 thinning，并关闭 relocation 与 opacity regularizer。它为短动态片段提供简单、可运行的基线，也会增加时间冗余和体积压力。

作者报告的 PSNR、splat 数与文件大小来自特定篮球片段、裁剪和留出设置，本期没有复现。仓库代码为 MIT，上游训练分支、数据和权重仍需单独核对。

[配方提交](https://github.com/arrival-space/animated-sog/commit/05364cf2641ce80a95b12888625714b2657d467c)

## VideoRNG 尝试生成可重光照高斯资产

VideoRNG 先从文本或单图生成已知相机与光照条件的 RGBA 转台视频，再由视频 latent 前馈预测数百万各向异性 Gaussian；共享方向解码器和随机 Gaussian ray tracer 负责随视角与光照变化的外观。它瞄准毛发、羽毛和蛛网等难网格化结构，并用前景 token 与按成本采样控制预测规模。

目前只能核实论文和项目展示，没有训练或推理代码、权重与独立复现，因此它是表示与数据管线信号，不是可部署工具。

[论文原文](https://arxiv.org/abs/2611.25338) · [项目展示仓库](https://github.com/videorng/videorng.github.io)

## ArcGIS XR Viewer beta 初步接入 Gaussian splat 图层

Esri 让 Web Scene 中的高斯图层进入桌面和 VR 浏览，与 Reality Server 的 splat 生成能力形成初步链路。XR Viewer 仍在 Early Adopter beta，官方明确保留功能、视觉和性能限制，VR 草图也不能保存。

[官方更新](https://www.esri.com/arcgis-blog/products/arcgis/3d-gis/whats-new-in-xr-viewer-beta-november-2026)

## LichtFeld 改善 Windows portable 包与 MCP 启动

LichtFeld 把 portable 可执行文件放到包根目录，将运行库整理到 `bin`，并修正资源和 MCP 自动启动定位；后续提交避免第三方许可证读取停顿。它改善部署与启动，不改变训练和渲染质量，且尚无对应 release。

[portable 包提交](https://github.com/MrNeRF/LichtFeld-Studio/commit/f6d3885bba3993a29acb8dfcc5e758baa9b2c2ae) · [许可证读取修复](https://github.com/MrNeRF/LichtFeld-Studio/commit/a40b6f3f49417b10c3c847461080f283dff650f4)

## Randers 作品把 6 亿高斯放进浏览器交付

SuperSplat 作品页标注 606.8M splats、9.39 GB 和 6 km²，并提供多个细节档。作者称用 250 m cell、1 km tile 和接缝统一组织训练；这部分只是作者公开说明，未独立复现。

该作品适合作为大范围航摄高斯的 LOD、分块与在线浏览案例，而不是已开放训练工具或通用性能基准。
