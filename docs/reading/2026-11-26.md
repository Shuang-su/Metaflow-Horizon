## StorySplat 2.6 让两种 4D Gaussian 进入浏览器场景

StorySplat 2.6 可直接读取 Open4DGS `.trigsbin` 和 Animated SOG `.asog`，动态片段能够参与灯光、阴影、热点、触发和剪辑，不再只是逐帧文件播放器。播放要求 viewer 2.16.0 以上，WebGPU 与 WebGL 2 都在支持范围。

真正的限制在交付端：两种格式都不流式，整份文件下载后才出现；公开 Open4DGS 示例达到 319—817 MB，手机播放也尚未验证。免费版只允许公开非商业发布，自托管商业项目至少需要 Plus；[发布说明](https://radiancefields.com/storysplat-2-6-plays-open4dgs-and-animated-sog-4d-splats)和[价格页](https://storysplat.com/pricing/)应一起看。

## SuperSplat Viewer 把嵌入控制权交给宿主

SuperSplat Viewer 主干不再假设自己拥有整张页面：信息面板改由 `onInfo` 回调提供，全屏只覆盖宿主容器，滚轮和快捷键也能服从宿主。导出 HTML 还能设置经过转义的页面标题，Orbit/Fly 目标则用固定 28 px 光标保持近远一致。

这会改善多 viewer、iframe 和产品化嵌入，却也改变旧页面依赖的 UI 契约。[PR #374](https://github.com/playcanvas/supersplat-viewer/pull/374)已经合并，但没有对应正式 release；生产项目应锁提交回归，而不是让依赖范围自动漂移。

## LichtFeld 用对应点对齐两次独立采集

LichtFeld Studio 允许在两个独立视图中标注同一物理细节，用至少 3 对不共线点求出正统一尺度、旋转和平移。预览会给出尺度、RMS 残差和最差点对，并支持分离、叠加与联动相机；应用后只产生一个撤销记录。

它解决的是多次采集坐标不一致，不会自动寻找对应，也不把两份高斯合成一份。[PR #4184](https://github.com/MrNeRF/LichtFeld-Studio/pull/4184)只完成 Windows 和局部工作流验证，Linux 与完整 CI 仍待补齐。

## SplatTransform 补上 CSV 回读并隔离压缩坏值

CSV 现在既能写出也能读回，适合表格分析和调试；reader 会检查标准列组完整性，并明确使用 PLY 坐标空间和 32 位浮点。它仍是常驻内存的文本路径，不应被当成新的高效资产格式。

更关键的健壮性修复阻止一个 `NaN` 污染整个 256-splat compressed PLY chunk，同时保留 `-Infinity` 尺度代表的零厚度语义。[CSV PR](https://github.com/playcanvas/splat-transform/pull/382)与[NaN PR](https://github.com/playcanvas/splat-transform/pull/355)都已合并到主干，但尚未形成新 tag。

## Spirula 给网格和点云预览设定资源边界

Spirula 重做网格提取界面，让生成过程可以预览，并根据设备内存计算预览预算。数据集点云预览则最多显示 1,000 万点：对提交中提到的 5.85 亿点输入，GUI 不再为全部点分配主机和 GPU 缓冲，原始数据和训练输入不受抽样影响。

数据集任务结束后还可以直接运行命令，成功或失败都会触发、取消则跳过，且不经过 shell。[主提交](https://github.com/harry7557558/spirula-studio/commit/28a7bd624e3f297e3a4a42b7703fc850aa7d9391)尚未进入正式发行；自动命令适合通知和流水线，但也扩大了本地执行权限面。

## S-Mind 让“模型内部有没有三维场景”可以复现

S-Mind 在 Qwen3.5 4B/9B 中加入空间 token：先融合多个视图，再随着推理视角变化重新表达同一场景。作者不仅报告最终答题结果，还用 readout 检查隐藏状态里的三维点和相机，使“模型是否真的形成共享几何”成为可测问题。

代码、4B/9B 权重、SFT 数据和 notebook 已以 Apache-2.0 开放；训练配置使用 Python 3.12、CUDA 12.9，并以 H100 80 GB 为作者环境。作者报告最多提升 22.26 个点和约 100 倍推理速度，尚无独立复现。先用 4B checkpoint 跑公开 probe，比直接训练更合理。[论文](https://arxiv.org/abs/2611.28649) · [代码](https://github.com/KANABOON1/S-Mind)

## Niantic 尝试把无人机和地面定位放进同一空间图

Niantic Spatial 展示了把手机、360 相机、无人机、卫星影像与矢量地图放进统一模型的方向，并从消费级无人机图像生成带地理参照和尺度的 Gaussian splat。作者称航拍 VPS 在捕获区域内有 85%—90% 位姿与方向定位成功率。

这是一篇研究和产品方向文章，不是新 SDK 发布；样本量、误差阈值和场景分布没有公开，不能把数字外推到通用地图。它值得关注的仍是地面—空中数据的统一坐标、更新频率和授权边界。[官方文章](https://www.nianticspatial.com/blog/seeing-from-above)

## PartAgent 与 RoomTokens 都把三维结构变成中间表示

PartAgent 让 3D 专家提供结构区域、2D 多视图专家提供语义证据，再由 agent 选择检查、修复和组合动作。作者报告五个部件分割 benchmark 领先，但[官方仓库](https://github.com/yangcaoai/PartAgent_Agent_for_3D_Part_Seg)明确写着代码尚未发布（[论文](https://arxiv.org/abs/2611.32554)）。

RoomTokens 则用离散网格同时保存语义、实例身份和朝向，再在楼层平面约束下生成室内布局。它面向场景合成，不是扫描或 viewer；[MIT 仓库](https://github.com/3dlg-hcvc/RoomToken)目前也只有占位 README。两项都提供了值得跟踪的结构化路线，现阶段仍是论文与演示，而不是可下载工具。[论文](https://arxiv.org/abs/2611.30219)
