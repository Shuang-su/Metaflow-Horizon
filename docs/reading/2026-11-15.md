## NVIDIA 把高斯带入重照明与传感器仿真

ovrtx 0.7.0 首次把 Gaussian splat 的漫反射重照明和实验性 LiDAR 放进公开 SDK 发行，但它仍是预发布，重照明也不能去除采集光照。原生消费者必须同步处理类型、结果结构与 `ovstage` 依赖变化。

`ParticleFieldSHDiffuse.mdl` 可让 splat 接收路径追踪光照；实验性 WPM LiDAR 只对带 `lidarExtraSignals` 的 NuRec 资产有响应。排序、无效位置和 segmentation 也得到修复。最稳妥的采用方式是隔离升级、重编译原生扩展，并用固定资产比较 0.6.x 与 0.7.0。

[发行说明与兼容边界](https://github.com/NVIDIA-Omniverse/ovrtx/releases/tag/v0.7.0)

## Ropedia 把高斯场景与第一视角任务数据配对

Ropedia Xperience 2 把度量尺度扫描、Gaussian splat 与 131 小时第一视角任务录像组织进同一 Physical AI 语料。论文描述 1,589 个场景，但当前 Hugging Face 可见的是 126 场景首批子集，且数据为非商业许可。

单场景可同时提供 PLY、网格、COLMAP 相机、鱼眼图像、遮罩和行为记录，让定位、任务理解、仿真与策略生成共享空间坐标。它的价值不只是新视角合成，而是把“环境是什么”与“人在其中做什么”连起来。

[论文原文](https://arxiv.org/abs/2611.17060) · [首批数据](https://huggingface.co/datasets/ropedia-ai/Ropedia-Xperience-2) · [代码](https://github.com/Ropedia/Ropedia-Xperience-2)

## Splattic 在浏览器里直接剪辑 4DGS

Splattic 4.0.0 把 4DGS 裁切、局部删除、简化、拼接和发布放进浏览器，但仍是商业应用公测版。本期未在手机或头显实测，也没有把编辑器与开源 4DGS SDK 混为同一许可。

选区可以跟随 splat 穿过时间，删除可限制在 IN/OUT 范围并保持非破坏；导出覆盖场景 zip、HTML sidecar、AR bundle 和 HTTP Range streaming。团队现在可以拿一段短 `.4dgs` 做端到端小样，但大文件内存、seek、首帧和移动设备播放仍需自测。

[官方更新记录](https://www.splattic.com/landing/changelog.html)

## SPZ 找回旧版文件中被丢弃的扩展记录

旧 gzip SPZ v1—v3 的内存流不能 seek，导致 extension records 在加载时被拒绝。主干修复并增加 v2/v3 round-trip 测试；基础 splat 数据不在本次缺陷范围内，也还没有新 release tag。

[合并记录](https://github.com/nianticlabs/spz/pull/115)

## Spirula 压缩训练掩码并增加 densify 稳定性开关

Spirula 把 visibility mask 改成位打包，并重做部分显存与 ETA 预测。作者的 7500 万 pair 示例中单项掩码大幅缩小，但完整进程降幅远小于该比例，不能把局部数字当成端到端显存提升。

新增的 `densify_min_split_opacity` 可以阻止低透明度 splat 继续分裂，但默认关闭，启用后也可能让增长达不到配额。两项都只在主干，适合锁提交 A/B。

[显存与预测提交](https://github.com/harry7557558/spirula-studio/commit/6e4f668402a315e819b78fb7f3e542c910c102fb) · [densify 门槛提交](https://github.com/harry7557558/spirula-studio/commit/6caadf0c1101bf934a58d5ecd16764ed5c9db057)
