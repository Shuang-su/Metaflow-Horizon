## Animated SOG 把 4D 高斯装进一个可流式播放的文件

`.asog` v1 把运动高斯、球谐和可选音频放进单文件，并同时给出 Python 编码器、流式 JavaScript 解码器、PlayCanvas WebGPU/WebGL 与 Three.js WebGL 2 播放器。对网页交付来说，它把逐帧 PLY/SOG 文件夹收束成可缓存、可渐进下载的资产。

作者样例显示约 11 倍体积缩减，但结果依赖资产、修剪和硬件。格式沿用 SOG v2 静态压缩、采用 TRiGS 运动模型，flip-book 管线还要 CUDA 与外部 AGPL Open4DGS；仓库没有正式 release，播放器依赖少量 PlayCanvas 2.22 内部 API。

[格式与工具链](https://github.com/arrival-space/animated-sog) · [PlayCanvas 样例](https://arrival-space.github.io/animated-sog/examples/playcanvas/) · [Three.js 样例](https://arrival-space.github.io/animated-sog/examples/three/)

## LichtFeld 自动预选模糊相机，并让 Save As 后的数据引用更可靠

LichtFeld 主干加入 Select Blurry，把清晰度评分并行化、缓存到项目会话，并让已驻留 GPU 的视频帧在 CUDA 上评分后再回读。它减少人工翻图，却不是可以直接批量删除相机的质量保证；运动模糊、景深虚化和低纹理仍需抽样复核。

同一批提交修复嵌入数据、迁移外部数据以及首次 Save As 后的相机路径，使相邻数据集继续保持可移动引用。变化都没有进入正式 tag，跨机器或外置盘项目应锁提交验证保存、移动、缺图恢复和重新打开。

[Select Blurry](https://github.com/MrNeRF/LichtFeld-Studio/commit/55a0c6e4235a0d5aa8e6f48a3c9291898aa256f0) · [CUDA 评分](https://github.com/MrNeRF/LichtFeld-Studio/commit/3d138e7583a39384539ae25da3a62863a81ab17f) · [Save As 可移植性](https://github.com/MrNeRF/LichtFeld-Studio/commit/719f36356c159dfabc7c75ce04be5d9c43d4a711)

## VDC Viewer 把 3DGS、BIM 和现场协作放进同一浏览器产品

VDC Viewer 月费 50,000 日元起，支持 PC 与平板，把 3DGS、BIM/网格、360°全景和 DXF 图纸放在同一空间，提供量测、注释、模型叠加、URL 分享、项目权限、MFA/SSO 和日本境内数据存储。

官方列出的高斯格式覆盖 PLY、compressed PLY、SOG、SPZ、LCC/LCC2 等，并声称可处理数千万点和厘米级测量。本期没有取得公开硬件、网络和误差样本；采购前应以真实项目测试转换时间、平板帧率、坐标对齐、量测误差和数据退出机制。

[公司公告](https://prtimes.jp/main/html/rd/p/000000001.000194723.html) · [产品页](https://vdcjp.com/vdc-viewer/)

## Spirula 收紧 3DGUT 与 2DGS 的 tile 相交和剔除

Spirula 主干改进 Gaussian—tile 相交与 culling，目标是避免过松测试带来无效排序/光栅工作，也避免过紧测试裁掉边缘贡献。它是前一日 2DGS、TSDF 与网格更新的后续修正，不是一套新的 primitive。

维护者没有给出完整性能数字，正式 release 也尚未包含该提交。测试应覆盖近裁面、大椭圆、斜视 surfel、广角和鱼眼相机，并同时记录像素差、边缘缺失、tile 工作量和耗时。

[主干提交](https://github.com/harry7557558/spirula-studio/commit/254eb5efd4561c314604855c407fc1a83a478d20)

## PaveSplat 让 feed-forward surfel 在放大后继续覆盖表面

PaveSplat 在解析表面对齐协方差上学习四元数残差，修正训练分辨率下被一像素 footprint 掩盖、到 2×—8× 重渲染才暴露的 surfel 朝向和表面空洞。论文把收益重点放在高分辨率复用，而不是原生分辨率的小幅指标变化。

作者已公开代码、两个 ViT-L 权重、哈希和复现脚本；测试栈为 Python 3.12、PyTorch 2.7.1/CUDA 12.8，论文训练使用两张 GPU 和 150k optimizer steps。代码、rasterizer 与权重均有非商业或 research-only 许可，适合先做权重评估，不宜直接进入商业依赖。

[论文](https://arxiv.org/abs/2611.26045) · [代码与复现说明](https://github.com/janghunn/pavesplat) · [权重](https://huggingface.co/janghunn/pavesplat)

## Quest 大场景交付分成端侧 LOD 与 PC 串流

SplatBox 1.3 采用分页 LOD、固定显存图集和 GPU 排序，把大场景留在 Quest 3 端侧；Splatara Cloud Renderer 则在 PC 渲染，再向最多四台 Quest 串流，并加入共位和现实遮挡。前者换取离线与本地交付，后者用 PC、网络和延迟预算换更大资产。

SplatBox 的原始 X 帖本轮不可读，商店也没有独立 1.3 changelog；730 万 splat 和促销价格应按媒体/作者转述理解。两条路线都需要在目标场地按同一资产、路由器、PC GPU、头显数量和持续运行时间验收。

[SplatBox 发现记录](https://radiancefields.com/daniel-skaale-releases-splatbox-1-3-for-unity) · [Splatara](https://splatara.cloud/)

## Splat Paint 与 Vintage Click 把高斯变成绘画和摄影媒介

Splat Paint 在浏览器里把输入 PLY 变成固定于三维空间的油画笔触，适合观察高斯的非写实表现；仓库没有声明许可证，目前不应直接复用到产品。Vintage Click 0.6.1 则在高斯扫描中模拟 1970 年代相机、镜头、胶片和有体积的 splat 积雪。

Vintage Click 为 GPL-3.0，当前 0.6.1 构建只面向 Apple Silicon 与 macOS 15.2+，Windows 版本落后一代。两者共同说明，创作者开始把高斯当作可编程视觉材料，而不只是重建输出。

[Splat Paint](https://github.com/remorses/splat-paint) · [Vintage Click 0.6.1](https://github.com/timfennell/vintage-click/releases/tag/v0.6.1)

## 高斯研究扩展到超分、冷冻电镜与参数合并式重照明

AGSR 在推理期收缩投影协方差，并融合多 aperture 渲染来恢复 footprint 压掉的细节；它获 MMSP 2026 Best Paper，当前没有找到作者代码。CryoGaussian 把显式高斯密度拟合到冷冻电镜粒子图像，面向稀有组成和连续构象，作者报告专用 rasterizer 带来 12.8—28.0 倍训练加速。

MergeableRF 则让共享几何、不同 basis light 的外观网络能够直接合并参数，一次渲染得到目标光照，同时覆盖 NeRF 与 3DGS。它仍要求已知 basis lights 的多视图采集。三篇目前都应按论文结果理解，性能与质量数字不能脱离各自任务和数据集外推。

[AGSR](https://arxiv.org/abs/2611.25934) · [CryoGaussian](https://arxiv.org/abs/2611.26128) · [MergeableRF](https://arxiv.org/abs/2611.25523)
