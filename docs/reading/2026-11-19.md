## Open4DGS 用画面运动补上多机位硬件同步

Open4DGS 把消费级多机位视频变成动态高斯：先从极线运动估计相机间的亚帧偏移与滚动快门读出，再用 RoMa v2、MEMFOF 和 TRiGS 路线初始化、训练与导出。Core 与训练器分别采用 MIT 和 AGPL-3.0，公开数据另有非商用限制。

现在最需要看到的是边界而不是宣传语。仓库把自己称为初始研究发布，分拆版本尚未完成一次全新端到端 GPU 跑通；测试环境集中在 Ubuntu 24.04、Python 3.11、CUDA 12.8 与 RTX 3090。`.trigsbin` 仍是大体量中间格式，不支持当前所说的 streaming，Unity、Web SDK 与压缩也只是 roadmap。

[项目页](https://open4dgs.asunemlabs.com/) · [准备与导出代码](https://github.com/ASU-NEM-Labs/open4dgs-core) · [训练器](https://github.com/ASU-NEM-Labs/open4dgs-trigs)

## ArcGIS Reality Server 把高斯生成放进企业任务队列

ArcGIS Reality Server 随 Enterprise 12.2 正式 GA，能在自管服务器或私有云上分布式处理无人机、航空和卫星影像，并把 Gaussian splat 与 true ortho、DSM、点云和网格一起作为产品。ArcGIS Pro、Python API、REST API 和 beta Web App 提供了桌面、自动化与浏览器入口。

这条路线面向已经有 ArcGIS Enterprise、数据治理和多人协作需求的组织。每台参与高斯处理的服务器至少需要 64 GB 内存、8 GB NVIDIA 显存、计算能力 7.5 与 CUDA 13；价格仍需联系客户经理。个人扫描用户不会因为它 GA 就得到更轻的工作流。

[Esri 正式公告](https://www.esri.com/arcgis-blog/products/arcgis-reality-server/imagery/arcgis-reality-server-is-now-available)

## Spirula 把 2DGS 训练和 TSDF 网格出口接到一起

Spirula 的新主干可以直接训练 2DGS surfel，并用 `spirula mesh --method tsdf` 从各相机的中值深度融合表面。CUDA 与 Vulkan 都接入了相同的 ray-disc 求交；同一轮还加入 OpenGL 硬件栅格器回退、Voronoi 分区和更准确的渐进分辨率显存预测。

作者的对照给出了适用边界：在 action-camera 样例里，2DGS 用 TSDF 与 opacity field 的网格 F-score 接近；3DGS 用 TSDF 反而留下更多 floaters，F-score 更低。TSDF 因此是 2DGS 的候选出口，而不是所有高斯模型的新默认。这些变化还没有正式 tag。

[2DGS 与 TSDF 合并提交](https://github.com/harry7557558/spirula-studio/commit/5806955241ec653a1ba279cf2e73dc17e6d03cba) · [低显存显示路径](https://github.com/harry7557558/spirula-studio/commit/303d1c6fdfaeaab1d604b18a78c7063a38dd7135)

## LichtFeld 用共享 pose 的针孔切片训练全景与鱼眼

LichtFeld 把一张等距柱状全景切为六个针孔视图，把覆盖半球以上的鱼眼切为五个视图，同时仍让这些派生视图共享原始照片的一套相机姿态。这样能复用快速栅格器，也避免相机优化把同一镜头的切片当成多台独立相机漂移。

后台 autosave 遇到显存不足时会延后快照，并保留部分捕获结果。这比让保存任务挤垮训练更稳健，但不保证快照完成；批处理仍需监控 deferred 状态。全景、鱼眼与快照变化都只在 GPL-3.0 主干。

[全景训练提交](https://github.com/MrNeRF/LichtFeld-Studio/commit/979ed5dee72e692150f2fa9072c60ef37d967cc7) · [超广角鱼眼提交](https://github.com/MrNeRF/LichtFeld-Studio/commit/db400bc3ff81110c897857cb307e20568e695cd5) · [快照显存处理](https://github.com/MrNeRF/LichtFeld-Studio/commit/73579832efa8c08c92f175708bd105d1a1ada987)

## ANNX Studio 在 Mac 上扩充训练模型并开放训练中预览

Radiance Fields 记录的 ANNX Studio 1.6.1 为 Apple Silicon 加入 MCMC、Xsplat 和默认 gsplat 训练，并允许训练时旋转查看中间结果。官方产品页确认 Mac/Windows、本地处理和许可分层，但没有提供公开的 1.6.1 独立 changelog，因此本期没有把它写成实测。

Basic 适合非商用入门，商业使用落在 Enterprise；训练预览会增加保存和显示开销。升级前应先用一份固定素材核对训练模式、墙钟时间、输出兼容性与停止任务后的结果完整度。

[产品与当前方案](https://annx.studio/) · [版本发现记录](https://radiancefields.com/annx-studio-1-6-1-brings-mcmc-and-xsplat-training-to-mac)

## DJI 用同一漫游出口承接网格、点云与高斯

DJI 的 World Heritage 3D Conservation Initiative 公布了龙门石窟、拉斯班塔斯斗牛场、武陵源和卡帕多奇亚等获奖项目。参赛者用 DJI Reality 把三维模型生成 MP4 漫游，输入可以是 mesh、point cloud 或 3DGS。

官方没有披露每个获奖项目具体用了哪种表示，因此不能把获奖作品全部算作高斯案例。更可靠的结论是，厂商已经把 3DGS 与传统航测结果放进同一个文化遗产交付入口。

[获奖作品](https://enterprise.dji.com/3dheritage-2026/awards)

## Pentimento 用 splat 记录施工现场为什么偏离 CAD

Pentimento 把现场视频、口述说明、Gaussian splat 和 CAD 模型注册到同一个浏览器时间线，用来记录回收木材施工中不断发生的临场调整。论文在 ACADIA’26 获 Best Paper，Cornell 的公告让这项 6 月首发、10 月更新的研究在本期成为行业应用新闻。

它是获奖原型，不是已经可以部署的产品。论文没有代码，评估主要是单一建筑案例与定性观察，也没有用户研究；它的价值在于提出了一种“把空间变化和变化原因一起保存”的记录方式。

[论文原文](https://arxiv.org/abs/2606.19609) · [Cornell 公告](https://news.cornell.edu/stories/2026/11/tracking-flaws-used-building-materials-facilitates-reuse)
