# Safari 渲染、连续跟手与稍后读投放修复计划

## 基线与完成标准

从执行时最新 Horizon main（执行开始为11279e2）建立独立修复分支，保留最新日报、文章身份、讨论键和阅读数据。以更新前玻璃、新录屏和iPhone故障图对照。必须解决矩形副本/正文重影/轮廓消失/封面硬切、异常蓝框、滚动步幅连续退出、侧滑投放、收藏与稍后读独立。本轮使用Astra High以上子代理分别处理光学、保存手势和独立复核，主代理集成共享组件。

## 光学、封面与焦点

- 对照5bbf9c0前后的承载方式，恢复普通HTML层承载SVG滤镜，撤除foreignObject[filter]。保留Glass-HQ材质、折射场、交互、Liquid Gooey菜单。
- 外层提供独立于filter的真实轮廓裁切：圆、胶囊、实时菜单形状；图标与材质同坐标/透明度/动画进度。失败不可露出矩形副本或第二份正文。
- 不以WebGL/PNG decode/DOM rect替代合成像素验收。保留故障回退，但不以Safari全站磨砂作为完成。
- 基础渐隐始终存在、与Canvas取色解耦。稳定mask放外层，blur/视差放图像；采色失败只影响环境色。光学采样同步祖先mask。
- 统一进入、目录、续读、从头阅读的程序焦点；非交互目标无UA蓝框，按钮/链接/输入键盘焦点保留。
- 同日更新入口显示日期和简短修订标题。

## 真正连续的顶部滚动进度

- 实际正文位移驱动连续q：下行退出、上行从当前进度返回，慢拉慢动、停住保持、反向立即接续。
- 删除120ms自动补完、1100ms输入有效期、逐帧小于1px丢弃；累计亚像素，以64CSSpx为完整行程，同距离不同速度结果一致。
- 返回向左、右侧成组向右，y中心固定且保持圆形；完全隐藏才停止命中。菜单/键盘焦点/正文顶部恢复可操作。
- 路由图标交叉淡变/外壳回弹与滚动独立；顶部进度不再通过共享布尔值触发底栏另一段定时退场。
- 纯可视高度变化只更新固定层锚点，不重置进度或取消侧滑；真实宽度/方向变化、多指和明确取消分别处理。

## 侧滑投放及独立收藏

- 仅站内有效来源的自定义右滑退出显示目标，系统边缘保持原行为。右下固定深灰四分之一圆+白托盘图标/文案；侧滑约15%W开始到60%W充分显现，半径约38%W，连续随幅度展开回收。
- 入目标高亮轻吸附、离开取消选中、目标内松手保存再返回。按触点命中，松手重查changedTouches最终坐标；目标外沿用正常返回/回弹。
- addReadLater必须幂等；重复投放不删除，失败回弹并提示，成功只返回一次并恢复来源滚动/轮播/焦点与数量。
- 直达/键盘/减少动态提供更多菜单加入操作。
- 底栏书签恢复收藏；更多菜单分别提供收藏紧凑列表和稍后读弧形列表。新增favoriteIds/toggleFavorite和幂等addReadLater，手势接口提供进度、坐标、投放结果。
- v2一条记录原子保存两个集合和迁移标记；当前稍后读复制收藏并合并能识别旧收藏，旧键保留恢复用途。此后独立增删，刷新不重新导入，跨标签页同步。空稍后读入口隐藏，最后移除后的空状态/撤销/焦点保留，仅本机标识和展示信息，无离线包/账号同步。

## 验收与上线

1. 原生Safari与Chromium：亮暗主题、亮暗封面、文字经过控件、菜单开合、连续返回；圆外无副本、正文单份、无双圈跳变、渐隐不中断。
2. 同距离慢拉/快拉/分段拉，暂停600ms、反向，q不自动补完；Safari地址栏高度变化不重置。
3. 投放进出、内外松手、重复、失败、多指、旋转、来源失效、焦点；独立保存迁移一次、刷新、跨标签页、撤销；触摸无标题蓝框但键盘仍有焦点。
4. 定向回归、类型、内容/媒体/来源、静态构建与导出检查；保留原文、锚点、RSS、讨论身份。
5. 更新Issue及记录、逐项前后/连续帧、本地checkpoint，更新4337预览。
6. 原生Safari通过并取得iPhone Safari对本次场景的复验后再提升生产。无真机结果则保留预览明确待验，不再以Chromium替代；生产回读SHA/页面/资源，异常只回退本轮界面而不丢最新内容。
