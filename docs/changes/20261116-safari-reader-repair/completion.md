## 已实现

- `fbdc36f`：恢复 HTML 光学层承载 SVG filter，撤除 `foreignObject[filter]`；由 Glass-HQ 的实际形状生成独立 polygon 裁切，保留原材质的窄边缘光。地图资源失败后隐藏全部采样副本，回退安全材质。不以 Safari 用户代理一律关闭折射。

- 程序聚焦的标题、段落和修订区使用临时非交互焦点标记，消除无意义的 UA 蓝框；键盘聚焦链接、按钮和输入仍有焦点提示。同日修订链接附简短标题。
- `5725fcd`：收藏和稍后读改为独立集合；v2 原子迁移保留旧队列和旧收藏，之后独立修改。迁移写入失败仍可读取旧记录并显示警告，修改失败不虚报成功。空稍后读入口隐藏，删除最后一项后的撤销/关闭焦点保留。
- 右滑退出中的四分之一圆托盘随 15%–60% 视口宽度展开，半径 38% 视口宽度；实际可见半径参与命中，松手重查最终触点。入目标高亮、离开取消，松手保存幂等；失败回弹并留在文章。托盘层高于固定底栏及其光学层，仍低于弹层。
