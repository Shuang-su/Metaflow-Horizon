# 高光精度与刷新时序修复

本轮基于 `33af672d2f2fa4d1839ee11469406058ef6e8059`，追加到草稿 PR #143，关联 Issue #137。iPhone 上一轮结果未通过；本轮只交付本地及独立测试部署，生产继续保持 `11279e223d8ad4e50d5ff80222a63af739a3f9cf`。任务提交 SHA、测试部署地址和回读回执在后续交付记录与 PR 回填。

## 实际修改

- 删除适配层强制 1×。静态控件和变形端点采用 `min(devicePixelRatio, 2)`；中间形状保留库提供的 DPR。缓存键包含实际栅格比例，显示密度变化重新准备资源。没有修改 Glass-HQ 的 shader 或光学模型。
- `readerFrame` 统一封面视差、滚动进度、控件退出与光学刷新。先推进本帧动画状态，再捕获冻结的背景几何/样式快照，最后批量投影。多个页面镜片共享一次背景捕获；滑块的局部滑轨单独采样。
- 缓存局部轮廓路径和源节点分类，纯平移不重新格式化 polygon；不变的 mask、样式、子节点不重复写入。保留每镜片 96 个片段上限、非相邻区域裁剪和独立轮廓，不复制整个长文、不恢复 foreignObject。
- 移植参考实现的 Worker 编码、解码 Image 保活与活跃材质 pin。常驻 decoded/encoded 各 16 MiB，需求过渡可分别临时借用 16 MiB，低优先级预热不能借用。Worker 不可用时按行/分片协作编码；实际导出中 Worker 是可独立加载的 JS，原 TS 与确定性生成检查一并保留。
- 字号菜单关闭后，在空闲时使用同一 JSX 的隐藏、inert、无正式 ID/role 的布局预测准备 Gooey 路径；实际菜单独立挂载。预测只接受真正静止的按钮，不使用路由呼吸、按压或退出中的瞬时尺寸。主题材料渐变保留，纯精度升级直接交接。
- 修复首次材质就绪时图标对比度迟一帧、Header 冗余 RAF/相同 class 写入导致背景失效的问题。

## 对照结果

原始紧凑结果见 [browser-results.json](browser-results.json)。基线和候选均在同一 Mac Chromium、566×939、DPR 2、同篇 11/12 正文、相同滚动区间运行。计数包含诊断包装成本，帧间隔不是纯 CPU 耗时，也不是 iPhone 帧率。

| 项目 | 旧基线 | 最终稳定复测 |
| --- | ---: | ---: |
| 40 帧位置读取 | 14,505 | 4,545（减少 68.7%） |
| 40 帧样式读取 | 5,117 | 2,073（减少 59.5%） |
| 材质 GPU 回读 | 0 | 0 |
| 稳定滚动新增材质 | 无本轮诊断接口 | 0 |
| 本轮统一帧/背景捕获/投影增量 | 无统一调度 | 39 / 39 / 39 |
| 帧间隔中位数 | 10.2–11.1 ms | 约 8.3 ms |
| 44 CSS px 静态按钮，DPR 2 / 3 | 48×48 | 96×96 |

DPR 1 对应 48×48；DPR 2、3 对应 96×96。IAB 的纯 DPR 覆盖改变查询结果但不发 resolution change 事件，因此该自动测试显式发 resize；真实跨屏事件机制仍须设备验证。实现同时监听 resolution、window 和 visual viewport 变化。

菜单时间分开记录：旧基线普通 DOM 点击首次材质约 139.8 ms；候选尚未加入预热时冷开 351.1 ms、热开 31.8 ms；最终完成预热后首次材质 31.9 ms、内容可交互 222.4 ms。实际鼠标按住约 60 ms 再松开的一次记录为 83.4 / 344.4 ms，按压改变路径并生成 18 个材料。不能把预热结果描述为所有首次点击或 iPhone 触摸的固定耗时。

**保留未解决的反证：** 实施中首次 40 帧诊断出现一次 558.4 ms 长帧，原因尚未确定；后续多轮稳定采样未重现。路径首次 trace 仍有同步 CPU 成本，用户在预热之前点击仍可能走冷路径。未宣称冷启动或 Safari 异步合成拖尾已经彻底解决。

## 验证

- 161 项站点测试、43 + 25 项 Python 测试通过。
- TypeScript、编辑、60 期内容/来源覆盖/媒体、静态构建与导出通过；99 HTML、3 RSS、60 原稿，内部链接/资源/锚点完整。正文、来源身份、RSS GUID、讨论键没有改变。
- 613×939 的圆按钮宽高差远小于 1 CSS px；下移 16 px 后 q=.75，停 650 ms 保持，反向 8 px 回到 .875。原位程序定位仍 q=1，无额外 DOM 背景/阴影，所有镜片使用独立 polygon，0 foreignObject。
- 24 px 字号后原可见正文锚点偏移约 0.16 CSS px；默认重置成功，Escape 后焦点回字号按钮。普通页面无诊断函数；减少动态/减少透明度回退正常，浏览器无警告或错误。
- Swiper 在 477、495、588、1441 px 下短甩、长拖、浅拖回弹、横滚尾段/反向、竖滚、过渡途中重新抓取通过；五张背景最后稳定帧副本位置误差 0，三个首页控件始终有光学源。触摸路径的合成 PointerEvent 不当作 iPhone 真机输入。
- 原生 macOS Safari 18.5 响应式 613×939、3×实际检查了亮色菜单、明暗切换、慢滚与反向、黑字和蓝链经过底栏；未见旧矩形泄露、外置第二圈或封面硬切。原生截图含浏览器个人栏，保留本机，不公开上传。
- 收藏、稍后读、续读、侧滑投放的已有事件/迁移/失败回弹测试随全套测试通过；未改变其产品协议。上一轮浏览器完整行为证据仍见 `../20261116-safari-reader-repair/`，本轮没有把未重新跑的真机步骤写成通过。

## 独立复核与发布边界

Astra High 独立复核发现的资源预算等待、预热真实 `0px` 解析、路由缩放结束事件遗漏均已修复。复核者独立重跑 7 项预热测试后确认两项预热缺陷关闭，限定范围无新增阻断项。构建 Worker 的 raw TS 资产失败也已修为独立 JS，并有完整字节一致性检查。

**iPhone Safari 新版本验收仍为待验。** 新预览需检查高光清晰度、持续慢滚停住、立即反向、地址栏收放、冷开与再次打开字号菜单。若仍有多帧追赶，保留测试版本并继续评估合成路径，不合并提升生产。本轮不改变定时发布流程，不计入每日 08:00 定时成功次数。

回退测试预览可重新指向已保存的 33af672 构建；生产不需要回退，因为本轮没有发布生产。系统盘构建，未清理用户文件；仅恢复本轮构建产生的三份无关分享图字节漂移。
